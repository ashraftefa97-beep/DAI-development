# Hardware profile

Reference target:
- ESP32-S3 with PSRAM
- 240x280 touch LCD (ST7789V2 class)
- BLE/Wi-Fi
- I2S/PDM microphone
- I2S speaker path
- haptic output
- battery/power management

Drivers remain board-specific. Do not connect or modify lithium batteries as part of software bring-up; use a complete supported development board and its normal USB interface.
